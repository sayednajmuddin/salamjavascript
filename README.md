## PDF to Word Converter for Dari and Pashto

This repository also contains a small PyQt5 application that converts PDF files to Word documents. It supports OCR for Dari and Pashto languages.

### Running

1. Install Python 3 and the dependencies:
   ```bash
   pip install -r pdf_to_word_app/requirements.txt
   ```
2. Run the GUI application:
   ```bash
   python pdf_to_word_app/pdf_converter.py
   ```

Use the interface to load your PDF and choose whether to use OCR.
